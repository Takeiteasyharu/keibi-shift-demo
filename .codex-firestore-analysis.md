# Firestore change analysis (2026-08-03)

Scope: new-account furigana and existing availability choices.

- `users/{uid}` is the existing PII profile document. Web registration creates it in the same batch as `employeeNumbers/{employeeNumber}` and `userRoles/{uid}`. The new optional schema field is `furigana`; web self-registration requires it, while legacy and managed profiles may omit it.
- `availability/{date_uid}` is the existing availability document. Its existing booleans are `day`, `night`, `unavailable`, and `undecided`. No path or collection is added. New UI writes `undecided: false` for compatibility.
- Availability reads remain scoped by the existing date, UID, branch, role, and ownership checks. Admin monthly rendering consumes the existing availability snapshot map.
- Rules retain default-deny behavior, validate `users` on create and update, prevent self-assigned roles, and validate all existing availability fields.

Red-team review for this change:

- Unknown user fields remain rejected by `hasOnly`; only `furigana` was added.
- Legacy profiles without `furigana` remain valid on update because the field is optional in the validator.
- New web registration cannot omit `furigana`; it is required in the owner-create branch.
- `furigana` is bounded to 1–80 kana/space characters, preventing type and oversized-string writes.
- Role, ownership, UID, timestamps, branch access, and availability permissions were not loosened.
- The availability document schema and owner UID checks are unchanged; four-choice mapping cannot change ownership or role data.
- Staff monthly availability uses `branchId == currentBranch` plus a bounded `date` range. This requires the composite `availability(branchId ASC, date ASC)` index. While it builds, the UI falls back to the Rules-compatible branch-only query and filters the selected month locally.
- Office profile edits may change optional `furigana`; `isValidUser` still validates kana type/length and the update rule still locks role, UID, branch, status, and creation metadata.
